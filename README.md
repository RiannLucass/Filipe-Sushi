# 🍣 Felipe Sushi — Apresentação Digital

Um projeto de site desenvolvido para o **Felipe Sushi**, com o objetivo de apresentar a identidade do restaurante, destacar seus pratos e proporcionar aos visitantes uma experiência visual agradável e intuitiva.

O projeto foi desenvolvido com foco em simplicidade, organização e responsividade, funcionando como uma extensão da presença digital do restaurante.

## 📌 Sobre o Projeto

O Felipe Sushi é um site institucional criado para apresentar o restaurante japonês de maneira moderna e elegante.

A proposta é oferecer aos visitantes um espaço onde possam conhecer um pouco da história, visualizar os pratos e acessar facilmente os canais de contato e redes sociais.

O design utiliza uma identidade visual clara, com elementos em vermelho e imagens em destaque, valorizando a apresentação dos alimentos e a experiência do usuário.

## ✨ Funcionalidades

- **Página inicial:** apresentação da identidade e proposta do restaurante.
- **Galeria de pratos:** exposição visual dos produtos e especialidades.
- **Navegação intuitiva:** acesso simplificado às diferentes áreas do site.
- **Integração com WhatsApp:** acesso direto ao canal de atendimento do restaurante.
- **Integração com Instagram:** direcionamento para o perfil oficial.
- **Design responsivo:** adaptação para computadores, tablets e dispositivos móveis.
- **Apresentação visual:** utilização de fotografias para valorizar os pratos e a identidade do estabelecimento.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Aplicação |
| --- | --- |
| HTML5 | Estruturação e organização das páginas |
| CSS3 | Estilização, layouts e responsividade |
| JavaScript | Funcionalidades e interações da interface |

## 🎨 Identidade Visual

O projeto foi desenvolvido com uma proposta visual limpa e sofisticada, utilizando:

- **Fundo claro:** proporciona leveza e organização.
- **Vermelho:** utilizado para destacar elementos e chamadas de ação.
- **Imagens em destaque:** valorizam os pratos e despertam o interesse visual.
- **Tipografia:** contribui para uma apresentação elegante e de fácil leitura.

## 📱 Responsividade

O site foi desenvolvido considerando diferentes tamanhos de tela, proporcionando uma experiência de navegação adaptada para:

- Computadores e notebooks.
- Tablets.
- Smartphones.

A versão mobile prioriza a organização dos elementos, a visualização das imagens e o acesso rápido aos contatos do restaurante.

## 📚 Objetivos de Aprendizado

Durante o desenvolvimento deste projeto, foram trabalhados conceitos importantes de desenvolvimento frontend:

- Estruturação de páginas com HTML5.
- Estilização e organização de layouts com CSS3.
- Manipulação de elementos e interações com JavaScript.
- Desenvolvimento de interfaces responsivas.
- Organização visual e hierarquia de informações.
- Integração de links externos para WhatsApp e Instagram.
- Aplicação de identidade visual em um projeto real.

## 👨‍💻 Desenvolvimento

Projeto desenvolvido como uma solução digital de apresentação para o restaurante Felipe Sushi, colocando em prática conhecimentos de desenvolvimento frontend e criação de interfaces web.

O projeto representa uma experiência de desenvolvimento voltada às necessidades de um negócio real, considerando identidade visual, experiência do usuário e presença digital.
